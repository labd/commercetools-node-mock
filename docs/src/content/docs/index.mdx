## Why @labdigital/commercetools-mock?

Testing code that talks to commercetools is hard. Hitting a real project is slow,
flaky, requires credentials, and pollutes shared data. Hand-written stubs drift
from the real API and never cover update actions, predicates, or reference
expansion.

`@labdigital/commercetools-mock` runs a faithful, in-memory implementation of the
commercetools REST API inside your test process. It speaks the same HTTP, so the
official [`@commercetools/platform-sdk`](https://www.npmjs.com/package/@commercetools/platform-sdk)
and any other HTTP client work against it unchanged.

## Install

Add the mock and its peer dependencies as dev dependencies:

<Tabs syncKey="pkg">
  <TabItem label="pnpm">
    ```bash
    pnpm add -D @labdigital/commercetools-mock msw @commercetools/platform-sdk
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm install --save-dev @labdigital/commercetools-mock msw @commercetools/platform-sdk
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add --dev @labdigital/commercetools-mock msw @commercetools/platform-sdk
    ```
  </TabItem>
</Tabs>

See [Installation](/commercetools-node-mock/getting-started/installation/) for
requirements and peer-dependency details.

## Quick taste

```typescript
import { CommercetoolsMock } from '@labdigital/commercetools-mock'
import { setupServer } from 'msw/node'

const ctMock = new CommercetoolsMock({ defaultProjectKey: 'my-project' })
const server = setupServer()

beforeAll(() => server.listen())
beforeEach(() => ctMock.registerHandlers(server))
afterEach(async () => {
  server.resetHandlers()
  await ctMock.clear()
})
afterAll(() => server.close())

test('the order is placed', async () => {
  // Create the data your code expects, through the API…
  await apiRoot.customers().post({ body: customerDraft }).execute()

  // …run the code under test (it uses the commercetools SDK)…
  const order = await placeOrder('jane@example.com')

  // …and assert on the result.
  expect(order.orderState).toBe('Open')
})
```
